{% load i18n %} {% comment %} The salary structure detail modal. It used to be three stacked blocks — employees, then a ten-column component table, then the worked example — inside a modal about 760px wide. Everything competed for the same vertical space: the component table scrolled sideways, the example's inputs sat halfway down the scroll, and its results appeared below the fold, so running an example meant scrolling away from the thing you were checking it against. Now: a summary bar of counts, then tabs — Components, Employees, Example, and the working behind the example once it has been run. They are separate readings of the same structure and are never needed on screen at once, which is exactly what tabs are for. Each panel then gets the full width of the modal rather than a third of its height. {% endcomment %}
