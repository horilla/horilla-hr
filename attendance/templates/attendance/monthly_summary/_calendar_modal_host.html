Regularising a conflict is the fix for the one problem that blocks a payroll run, and sending someone to another screen to do it -- then back, to run the review again -- is the sort of round trip that gets skipped. The JavaScript has to live here rather than in calendar_modal.html because scripts inserted through innerHTML do not execute; the modal's cells call these functions by name. Context (employee, dates, resolve URL) is read from the #cal-data element the modal template injects. Include this once per page, then call: window.openAttendanceCalendar(url) where url is `attendance-monthly-summary-calendar` with employee_id, from_date and to_date. {% endcomment %}
