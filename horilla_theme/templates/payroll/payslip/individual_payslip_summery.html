{% load static i18n horillafilters %} {% comment %} The payslip. It was six cards in a two-column masonry grid, so nothing lined up with anything: Net Pay beside Attendance, Employee Details beside Allowances, Deductions beside a gap. Amounts sat in a `flex-1` column whose left edge moved with the label beside it, so no two figures on the page shared an axis and the columns could not be scanned or added up by eye. A payslip is a statement of one arithmetic: earnings - deductions = net so it is laid out as that arithmetic. Earnings and deductions are two columns of the same table, each ending in its own total on the same baseline, and the net follows from them. Every figure is right-aligned on a shared axis with tabular numerals, which is what lets someone check a column by running a finger down it — the reason payslips and invoices have looked like this for a century. Everything above the arithmetic is context for it: who, which period, and what the pay was worked out from. Everything below is the caveats. {% endcomment %}

The four hour figures ARE the working, so each is shown — including the ones that came to nothing, because "no holiday overtime" is an answer and a missing row is not. {% endcomment %}
