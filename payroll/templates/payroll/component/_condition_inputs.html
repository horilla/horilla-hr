{% load i18n %} {% comment %} One extra condition row. The first row is the form's own `field` / `condition` / `value`. Further rows post as `other_fields` / `other_conditions` / `other_values`, which is what `MultipleCondition` reads them back from. The selects are written out from the bound fields' choices rather than cloned from the first row in JavaScript, which is how the old widget built them: a clone carries whatever state select2 had already put on the original, and an existing component's saved conditions had to be re-created and re-selected by a second script after render. Expects `field`, `condition` and `value` bound fields for their choices, plus `selected_*` for a row being restored. {% endcomment %}
