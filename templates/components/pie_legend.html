{% comment %} Shared donut/pie chart legend, the same one the main dashboard uses for Department Headcount: one row of chips, then a "+N" chip whose hover popover lists the rest with checkboxes. The first `topN` items start selected; unselected ones are zeroed out of the series, so the donut only carries what is ticked. Include once per dashboard page, before the page's chart script: {% include "components/pie_legend.html" %} Usage: const legend = PieLegend.forChart(chartEl, () => chartInstances[key], 'types'); legend.set(items.map((x, i) => ({ name: x.label, value: x.count, color: c }))); ... new ApexCharts(chartEl, { series: legend.series(), legend: { show: false }, ... }) legend.clear(); // when there is no data {% endcomment %}
