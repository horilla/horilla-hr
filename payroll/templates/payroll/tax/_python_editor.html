{% load i18n %} {% comment %} --------------------------------------------------------------------------- Built-in tax formula editor controls. Replaces a hard-coded https://onecompiler.com iframe that was the ONLY way to enter a formula. That arrangement had three problems beyond the obvious dependency on a third party being reachable: * the employer's tax formula was sent to another company to be edited; * the code reached the form only through a postMessage callback, so if the iframe was slow, blocked by CSP, or the admin saved first, python_code was stored EMPTY while use_py stayed on — and every payslip on that filing status then silently taxed at 0; * "Run" executed in onecompiler's sandbox against unrelated data, which said nothing about what this system would compute. This partial deliberately does NOT render {{ form.python_code }}. The surrounding form already renders it; rendering it again would put two inputs named python_code in the same form and let the browser decide which one is submitted. Instead this styles the existing textarea in place and adds the Test controls beneath it. --------------------------------------------------------------------------- {% endcomment %}
